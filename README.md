# 21届大学生智能汽车竞赛人工智能视觉组工程文件汇总
- 包括*机械设计 PCB设计 视觉数据集eIQ训练文件及tflite模型 视觉代码与主控代码* 全部完整开源！依据分支名即可查看对应部分工程文件
## 总结
- 人工智能视觉组是21届全新赛道，除传统的机械结构设计，PCB制作外，还融合麦轮全向高精度运动控制，视觉识别，路径规划，是新颖且综合性强的赛道，分工建议经典的控制+视觉+硬件组合，并且多联调，比如需要机械设计挡光减少光线对视觉识别的干扰同时较易拆卸，自制pcb往往不需要逐飞/龙邱上的很多模块具体需要硬件和控制敲定，视觉和控制的通讯需要约定格式etc.
- 一些tips(bugs)：ivCam要用1280*720尺寸及高帧率必须氪金 上位机偶发通信延时，有线比无线稳定性强非常多 i.MXRT1064核心板CR时序引脚bug多易锁住芯片，需要按住mode键同时按reset之后松开mode，方可重新烧录
总而言之，在四个月的时间里基本完成赛项并获奖，已经算是足够令人满意了。然而终究限于时间和能力，本仓库内文件虽已涵盖本赛道核心技术要点，仍在**路径规划以及路径转实际运动指令** **车模运动精度（包括前后左右移动距离及锁头，即编码器积分累计误差和imu漂移问题）** 两大问题上未能拿出更好的方案，希望之后能得到进一步完善！
